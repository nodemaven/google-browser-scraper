# google-browser-scraper is now gserp

This project was renamed to [gserp](https://pypi.org/project/gserp/).

```
pip install gserp
```

Installing `google-browser-scraper` installs `gserp` at the same version and
keeps the old names working: the `google-browser-scraper` command,
`import google_browser_scraper` (with a deprecation warning) and the `GBS_*`
environment variables. New code should use `gserp`, `import gserp` and
`GSERP_*`.

Source and documentation: https://github.com/nodemaven/gserp
